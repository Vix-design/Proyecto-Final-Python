# Calculadora de IMC

# Descripción

Este programa permite calcular el Índice de Masa Corporal (IMC) de una persona a partir de sus datos personales.

El programa solicita:

- Nombre
- Apellido paterno
- Apellido materno
- Edad
- Peso
- Estatura

Este valida que los campos de texto no estén vacíos, solicitando nuevamente la información cuando se ingresan datos incorrectos en los campos numéricos.

Después de colocar los datos de forma correcta, este calculara el IMC y mostrara el resultado con dos decimales.

# Instrucciones de ejecución

1. Abrir el proyecto en Visual Studio Code.
2. Seleccionar el archivo `calculadora_imc.py`.
3. Ejecutar el programa.
4. Ingresar el nombre y apellidos solicitados.
5. Introducir la edad, el peso y la estatura.
6. Si se ingresa un dato incorrecto, el programa mostrará un mensaje y solicitará nuevamente la información.
7. Al finalizar, este mostrará los datos ingresados y el resultado del IMC.
